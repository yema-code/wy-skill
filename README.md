### 🎯 核心功能

* **找客户 (Lead Generation)**：分析目标市场，挖掘潜在 B2B 买家特征及渠道。
* **写开发信 (Cold Email)**：根据不同市场与产品特点，生成高转化率的个性化开发信。
* **客户激活 (Lead Activation)**：针对沉睡客户或未回复询盘，设计针对性的跟进（Follow-up）话术。
* **背景调查 (Background Check)**：梳理目标公司的官网、社媒、关键决策人（Buyer/CEO）等背景信息。
* **营销战役 (Campaign Strategy)**：规划多渠道营销 Campaign 方案与触达节奏。
* **客户管理 (CRM Assistant)**：协助整理客户画像、分类归档及撰写 CRM 维护日志。

### ⚠️ 运行边界与安全原则

* **不执行自动外联**：本技能仅生成策略、话术、分析报告和邮件文本。**不会**自动调用任何自动化工具向客户发送邮件或拨打电话，所有外联操作需由业务员手动审核并执行。

### 🚀 使用方法

本技能已配置本地及云端快捷唤醒。在支持 Skill 加载的编辑器（如 Cursor / VS Code 等 Codex 环境）或 AI 聊天界面中，你可以通过以下方式调用： 

1. **输入快捷指令**： 

  * 输入 @wy
  * 或输入 `$wy`
2. **下达任务**：在唤醒词后直接输入你的具体外贸需求。

### 💡 使用示例

* @wy 帮我背调一下这家印度尼西亚的汽配进口商，分析他们的核心痛点。
* `$wy` 针对超过 3 个月未回复的欧洲工程机械客户，写一封激活跟进信。
