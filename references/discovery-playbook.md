# 客户发现与查询手册

本文件只在设计搜索式、补充候选来源或排查搜索覆盖不足时读取。评分和证据标准仍以 [research-quality.md](research-quality.md) 为准。

## 查询族

把产品、买家角色、采购/渠道意图、地理位置、本地语言和排除词组合成查询族；不要只反复替换产品同义词。

| 查询族 | 组合重点 | 适合发现 |
|---|---|---|
| 产品 + 买家角色 | 产品词 + importer/distributor/wholesaler/retailer/project buyer | 直接渠道客户 |
| 产品 + 商业意图 | 产品词 + supplier/brands/stockist/catalogue/private label | 有产品线或采购入口的公司 |
| 产品 + 应用场景 | 产品词 + hotel/hospitality/project/contract/retail | 垂直行业客户 |
| 角色 + 地理 | 买家角色 + 国家/城市/区域 | 本地渠道与中小企业 |
| 产品 + 本地语言 | 目标市场常用产品词和角色词 | 非英语官网与本地目录 |
| 竞品/替代品 + 渠道 | 品牌、替代材质或相近品类 + retailer/distributor | 渠道客户、互补产品机会 |
| 事件/组织来源 | 产品/行业 + exhibition/association/member/tender/project | 展会、协会、招标与项目线索 |

排除词按项目调整，常见有 `consumer`、`marketplace`、`jobs`、`pdf`、`used`、`repair` 和用户明确排除的客户类型。排除过强会漏掉真实公司，需保留原始查询式和调整原因。

## 来源拓展顺序

1. 公司官网和官网产品/项目/经销页面。
2. 政府注册、进口商名录、行业协会及认证机构成员页。
3. 展会参展商、会议讲者、招标/中标和项目资料。
4. 专业网络、公司官方社媒与公开团队页。
5. 竞品案例、合作伙伴、经销网络和客户案例。
6. 可信行业媒体、新闻和专业目录。

目录、搜索摘要和社媒帖子用于发现线索；最终结论必须回到原始页面。不能访问原页时进入 `review`，不得用摘要补成确定事实。

## 快速预筛

候选进入深度背调前，先检查：

- 是否为可识别经营实体且有可归属的官网域名。
- 是否位于或明确服务目标市场。
- 是否有产品、应用、渠道或客户类型匹配的直接证据。
- 是否命中硬排除项，或明显仅为消费者页面/聚合页。
- 是否与 CRM 中已有域名重复，或属于集团/品牌/子公司关系。

预筛结果只决定搜索资源优先级，不替代 100 分评分。招聘、社媒活跃、缺货或新品最多是待解释信号，不能单独确认采购需求。

## 覆盖记录

每批保存使用过的查询族、语言、市场、来源类型、新增候选数和新增合格数。达到目标或触发 [workflow.md](workflow.md) 的停止条件时结束；不要用推测邮箱或低质量公司填充数量。
