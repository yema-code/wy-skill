# TikTok B2B 获客辅助 SOP

本文件用于指导操作者以 TikTok 内容和直播获取 B2B 询盘，并把合格线索接入 WY 的研究、背调、开发信和客户激活流程。它只提供策划、检查、话术草稿和线索整理；不自动注册账号、发布、评论、私信或搬运第三方内容。

## 总流程

`市场与账号定位 → 可拍摄性检查 → 内容选题与脚本 → 发布/直播准备 → 询盘承接 → B2B 分级与核验 → 样品/报价 → CRM 跟进`

每次只推进一个阶段。阶段结束时向操作者展示已完成项、缺口、下一项建议和需要确认的对外声明。

## 1. 市场与账号定位

与操作者确认：目标国家/区域、主语言、买家类型、主推产品、典型采购场景、承接渠道和账号现状。一个账号应有清晰的市场、语言和内容主题；是否拆分多账号由内容能力和运营资源决定，不为“矩阵”而复制相同内容。

只使用 TikTok 提供的正常业务设置、地区/语言定位、广告或企业账号功能。不得指导代理/IP 轮换、设备指纹伪装、批量养号、反检测或规避平台限制。

输出：账号定位一句话、ICP、排除人群、内容支柱、语言、资料页 CTA 和承接负责人。

## 2. 供应链与可拍摄性检查

从 `supplier-profile.json` 核对：

- 可公开拍摄的工厂、仓库、展厅、质检、包装和装柜场景。
- 已授权展示的品牌、客户案例、工人、文件和生产数据。
- SKU、规格、MOQ、样品、库存、交期、价格边界和认证的最新状态。
- 工厂/仓库是否允许拍摄，是否会暴露客户、地址、订单、标签、图纸或商业秘密。

没有库存同步、交付能力或可验证卖点时，不建议放大推广。免费/低价样品、客户付运费等政策必须由操作者确认，不设为默认承诺。

## 3. 内容策划

内容支柱可组合：

- 真实供应链：生产、质检、包装、库存和交付流程。
- 产品证明：功能、材质、耐用、尺寸、对比和使用场景。
- 买家教育：选型、MOQ、定制、认证、包装、物流和常见采购错误。
- 市场本地化：当地尺寸、气候、渠道、审美和合规准备。
- 人员与服务：业务员、工程师或品控人员解释专业问题。

单条脚本使用 `Hook → Proof → Context → CTA`：

1. Hook：一个具体问题、可见差异或真实场景；不使用无法兑现的极低价、利润保证或虚假稀缺。
2. Proof：用镜头展示产品/流程/测试，并说明测试条件。
3. Context：说明适用买家、规格、MOQ 或应用边界。
4. CTA：邀请留言业务需求、查看资料页或使用公开业务入口；不诱导暴露私人信息。

交付每条脚本时列出镜头表、口播/字幕、要核验的声明、CTA 和二次剪辑方向。语言本地化需要操作者或合格译者复核。

## 4. 发布与直播准备

WY 可以生成发布检查单、标题/字幕/标签草稿、评论回复库和直播提纲。发布前人工检查：素材授权、产品事实、音乐/图片版权、平台规则、价格和库存时效、联系方式展示方式、当地广告/促销要求。

直播提纲优先：开场定位、产品演示、常见采购问题、MOQ/样品边界、工厂/仓库展示、询盘 CTA。不得展示未授权订单、客户信息、付款资料或实时仓储安防细节。

## 5. 询盘承接

公开评论先用简短业务回复引导对方说明公司、国家、采购用途和数量区间；私信或资料页承接时使用操作者批准的公开业务邮箱、WhatsApp Business 或官网表单。不要把个人手机号、私人账号或平台外迁移作为强制步骤。

首次承接收集最少必要信息：公司/品牌、官网或公开主页、国家、角色、产品、用途、数量/MOQ、目标时间和希望的下一步。将原始表述与后续核验结论分开保存。

## 6. B2B 分级与核验

- A：公司身份可识别，有明确产品、数量、时间或项目需求。优先快速人工响应并进入 L2 背调。
- B：公司可识别且匹配，但数量/时间未确认。先补发现问题，可建议样品或规格交换。
- C：信息不足、零售需求、泛咨询或身份无法核验。提供公开资料或澄清问题，不直接标为合格 B2B 客户。
- Risk hold：疑似冒充、异常付款/物流、受限主体、信息冲突或要求绕过正常交易控制。暂停并按 [due-diligence.md](due-diligence.md) 核验。

等级不是永久标签。完成官网、公司、联系人和需求核验后，使用现有 100 分模型决定 `qualified/review/rejected`，不以粉丝数或私信热情代替客户评分。

## 7. 转化与 CRM

A/B 线索进入：公司去重 → 联系人/入口核验 → 背调 → 开发信/承接话术 → 样品或报价 → 激活案例。视频通话、样品、报价和物流承诺都由操作者确认；报价需包含配置、阶梯数量、币种、Incoterms、物流/税费边界、交期条件和有效期。

从 `assets/templates/tiktok-lead-intake.json` 复制询盘记录。确认是企业后再用 `upsert-company`、`upsert-contact` 和 `add-evidence` 写入 CRM；TikTok 账号和消息 URL 只能作为线索来源，不能单独证明公司身份或采购能力。

## 8. 复盘

按市场、内容支柱、SKU 和买家阶段复盘：合格 B2B 询盘、可识别公司、进入背调、规格交换、样品、报价和成交。播放、点赞和粉丝增长是内容指标，不等于获客质量。

每轮只调整一个主要变量，例如 Hook、证明方式、SKU、语言或 CTA。记录样本量、观察窗口和替代解释，不承诺固定转化率。
