# 集成与输出

## 通用原则

先检查当前环境实际可用的连接器、MCP、CLI 或浏览器能力，不根据说明书假设 Notion 或搜索 API 已连接。配置缺失时说明缺什么，并继续使用本地数据库；不要伪造连接成功。

凭据不得写进 `SKILL.md`、项目数据库、导出文件、命令历史示例或聊天正文。优先使用产品的凭据管理、环境变量或已授权连接器。扩展 Python 脚本时统一调用 `get_runtime_secret()`，由它通过 `os.environ.get()` 在运行时读取；不要直接写入真实值或回显密钥。

## Notion CRM

Notion 是本地 CRM 的可选视图/协作目标，不是研究过程的唯一状态源。

首次连接时：

1. 检查是否已有目标数据库和唯一标识字段。
2. 提议字段映射：公司域名、公司名、国家、客户类型、评分与分项、阶段、摘要、风险、未知项、联系人、竞品基准、企业社媒、证据 URL、观察日期。
3. 向用户预览将创建或变更的数据库、属性和记录数量。
4. 用户明确确认后才创建数据库或写入。
5. 按规范化域名 upsert；联系人按公司、姓名、职位 upsert。
6. 同步后抽查新增、更新、跳过和冲突记录，并保留本地数据库。

冲突默认不覆盖较新的非空人工值。把本地值、远端值和更新时间列给用户选择；只有能证明一个值更新且来源可靠时才自动采用。

连接器不可用时，导出 CSV 或格式化 XLSX，给出可映射字段，不要求用户在对话中粘贴 token。

## 备用搜索提供方

备用搜索只用于发现候选 URL，不能替代原始页面核验。

- 当前提供方被限流、验证码阻断或不可用时先保存进度并停止重复请求。
- 只有用户明确选择且环境中存在已配置的备用提供方时才切换。
- 记录提供方、查询、时间和候选 URL；最终证据仍指向原始公司、注册、职业或新闻页面。
- API 只返回摘要且原页不可访问时，将结论标为低置信度 `review`。
- 不代替用户处理验证码，不绕过访问限制。

## Excel、CSV 与 PDF

- CSV：最稳定的交换格式，直接由 `scripts/wy_crm.py export` 生成。
- XLSX：适合筛选、冻结表头、条件格式和多表关联。多区域研究宜分为市场、客户、联系人、竞品需求、社媒、行动队列和证据视图。使用 spreadsheet skill 创建和验证。
- PDF：适合阅读和分享公司报告，不作为可继续更新的主数据源。使用 PDF skill 创建、渲染并检查。
- Notion：适合持续协作，但同步前必须处理字段映射与冲突。

默认先保留本地 SQLite，再按用户用途选择一种或多种输出。外部写入与覆盖始终在执行前预览并取得确认。
